# ШторCRM — CRM и Учёт для салонов штор

## Обзор проекта
- **Название**: ШторCRM
- **Цель**: Лендинг-страница CRM-системы для дизайнеров по текстилю и салонов штор (по образцу aspiot.ru)
- **Стек**: Hono + TypeScript + Tailwind CSS (CDN) + Cloudflare Pages

## Реализованные секции

| Секция | Описание |
|--------|----------|
| **Header** | Фиксированная навигация с мобильным меню, логотип, CTA-кнопка |
| **Hero** | Главный экран с градиентом, мокапом дашборда, CTA-кнопками |
| **Stats** | Счётчик: 500+ салонов, 15K+ проектов, 4 страны, 98% довольных |
| **Интеграции** | Карточки: Instagram, WhatsApp, Telegram, 1С |
| **Возможности** | 4 карточки: Продажи, Поставщики, Аналитика, Финансы |
| **Начало работы** | 4 шага: Регистрация → Созвон → Тест → Поддержка |
| **Тарифы** | 4 тарифа с переключателем 12/6 месяцев, плашка «Популярный» |
| **Отзывы** | 3 отзыва клиентов с рейтингом ★★★★★ |
| **Мобильное приложение** | Мокап телефона с функциями приложения |
| **USP** | 3 преимущества на фирменном фоне |
| **FAQ** | 6 вопросов с аккордеоном |
| **CTA** | Финальный призыв к действию |
| **Footer** | Контакты, ссылки, соцсети, правовая информация |

## Интерактивность
- Переключатель тарифов (12 / 6 месяцев) с анимацией цен
- FAQ-аккордеон (открытие/закрытие)
- Мобильное меню (бургер)
- Scroll-анимации (fade-up) через Intersection Observer
- Плавная прокрутка к секциям
- Hover-эффекты на карточках
